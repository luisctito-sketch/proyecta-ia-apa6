# PROYECTA-IA — Citas y Referencias APA 6

Herramienta transversal para apoyar todo el Proyecto de Grado.

## Contenidos
- Citas textuales menores de 40 palabras.
- Citas textuales de 40 palabras o más.
- Citas basadas en el autor y en el texto.
- Citas parafraseadas.
- Reglas según número de autores.
- Autor corporativo y cita de una cita.
- Referencias de libros, capítulos, artículos, tesis, informes, web y congresos.
- Revisor de párrafos.
- Prompt de auditoría profunda para ChatGPT.

## Integridad académica
El módulo no inventa autor, año, página, DOI, URL, editorial, revista ni institución. Si falta un dato, lo marca como faltante.

## Acceso centralizado
Este módulo carga el mismo archivo central que todos los chatbots:

`https://luisctito-sketch.github.io/proyecta-ia-acceso/access.js`

Cuando se incorporen nuevos estudiantes, solo se actualiza `access.js` en el repositorio `proyecta-ia-acceso`. No es necesario modificar este módulo.
